## 模块一：作品简介 (按字数限制分版本)

### 版本 A：精简版 (约 300 字，适用于字数上限严格为 300~500 字的表单字段)

UniScholar (联智学者) 紧扣中国联通浙江分公司产业命题，针对高校师生在科研全流程中面临的“文献检索耗时、大纲梳理繁杂、数据统计低效、国标引文排版繁琐、流程割裂”等痛点，依托联通元景大模型与万悟智能体平台架构，自主研发了面向高校科研人员的通用智能体工作台。

系统创新性提出基于有向无环图（DAG）的双层人在回路（HITL）机制，支持断点无损续跑与人工干预；构建多源递归检索与抗脱靶算法，实现精准文献召回；首创纯中文学术纯化与 Pydantic 强类型防幻觉信息抽取，并引入 Citation Validator 引文双向交叉白名单校验；内置国标 GB/T 7714 格式引擎与 Tukey IQR 实验数据可视化。经多学科实测，系统可将科研前期事务性工时压缩 80% 以上，为高校科研数字化转型与联通元景生态产业落地提供可复制推广的标杆示范。

### 版本 B：详尽版 (约 800 字，适用于项目详细介绍 / 申报书前言)

**【背景与痛点】**  
在高校科研与研究生培养中，文献检索、核心观点提炼、实验数据分析和参考文献排版等前置事务性工作占据了科研人员超过 70% 的宝贵精力。通用大模型在科研场景中常面临“跨领域检索脱靶、中英混合病句、虚构伪造引文（幻觉）、黑盒自动化缺乏可控性”等瓶颈，难以真正嵌入严谨的高校学术工作流。

**【产品定位与联通对齐】**  
围绕中国联合网络通信有限公司浙江省分公司发布的“基于通用智能体的AI科研智能体应用开发”产业命题，长沙师范学院团队依托电子商务与财务管理跨学科优势，在王博林副教授指导下，自主设计并研发了 UniScholar (联智学者) 高校科研通用智能体工作台。系统深度对标中国联通元景大模型与万悟智能体平台标准，打造高可靠、端到端、人在回路的高校科研通用智能体应用。

**【核心技术创新与五大功能】**  
1. **DAG 状态机与人在回路 (HITL)**：基于有向无环图驱动工作流，支持 Checkpoint 序列化与断点续跑；在文献筛选与大纲推演节点支持学者随时干预校准，解决大模型黑盒不可控难题。
2. **多源递归检索与防脱靶算法**：融合 OpenAlex、Europe PMC 与 arXiv 跨库召回，结合核心领域词元强约束与加权语义打分，彻底杜绝跨领域杂质文献。
3. **防幻觉信息抽取与纯中文纯化**：基于 Pydantic Schema 强类型约束抽取研究背景、创新点与实验方法，结合学术语言纯化器消除机翻混合病句，生成结构严谨的三级综述大纲初稿。
4. **Citation Validator 引文双向白名单校验**：建立引文白名单映射矩阵，逐句核查综述生成引文的真实性并打标，确保引文 100% 真实可溯源。
5. **国标 GB/T 7714-2015 排版与科研数据可视化**：支持 GB/T 7714、APA、IEEE 一键无损排版并提供缺失要素审计；集成 Pandas 统计与 Tukey IQR 算法，一键生成学术级可视化图表。

**【应用成效与社会价值】**  
系统经多学科实测，成功将文献准备与格式整理周期从 3~5 天压缩至 15 分钟以内，释放科研人员 80% 以上的事务性重复劳动。代码已全面开源并在 GitHub 持续迭代，全面赋能高校科研数字化，助力联通“元景+万悟”生态在高等教育场景的纵深拓展。
